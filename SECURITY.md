# Security policy

## Supported versions

Before the first stable release, security fixes are made on the current release-candidate branch. After publication, the latest package minor is supported and labeled `support:X.Y`.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/neuroqp/neuroqp-python/security/advisories/new). Do not open a public issue, discussion, or pull request.

Include the affected package version, export format version, impact, reproduction steps, and a minimal synthetic proof of concept. Do not upload a real NeuroQP project export or sensitive research data.

The maintainers will acknowledge the report, investigate it privately, and coordinate a fix and disclosure. Please allow time for a safe release before publishing details.
