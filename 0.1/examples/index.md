# Example notebooks

Use these notebooks as starting points for your own NeuroQP analysis. They work with the downloadable [synthetic v2 export](https://python.neuroqp.com/0.1/assets/downloads/neuroqp-example-v2.zip), so you can explore the package before using your own project data.

- [Open and navigate an export](https://python.neuroqp.com/0.1/examples/open-and-navigate/index.md)
- [Validate an export](https://python.neuroqp.com/0.1/examples/validate-export/index.md)

Open a notebook in the documentation to read it, or use its download control to run and adapt the source locally. A downloaded notebook stores the small synthetic export beside itself the first time it runs. To use your own data, change `PROJECT_FILE` to the path of your project export.
