# Support

## Questions

Use [GitHub Discussions](https://github.com/neuroqp/neuroqp-python/discussions) for usage questions and ideas that are not yet concrete feature requests.

## Bugs and feature requests

Use the repository’s structured [issue forms](https://github.com/neuroqp/neuroqp-python/issues/new/choose). Include the SDK version, Python version, operating system, command or minimal code, and full error text.

Do not attach private project exports. Create a minimal synthetic reproducer or share only redacted validation output.

## Security reports

Do not open a public issue for a vulnerability. Follow the private reporting process in the [security policy](https://github.com/neuroqp/neuroqp-python/security/policy).

## Supported versions

Until `0.1.0` is published, only the current release-candidate branch is supported. After publication, security fixes target the latest package minor and its supported export formats.
