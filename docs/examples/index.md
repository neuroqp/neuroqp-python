# Example notebooks

Use these notebooks as starting points for your own NeuroQP analysis. They work with the downloadable [synthetic v2 export](../assets/downloads/neuroqp-example-v2.zip), so you can explore the package before using your own project data.

- [Open and navigate an export](open-and-navigate.ipynb)
- [Validate an export](validate-export.ipynb)

Open a notebook in the documentation to read it, or use its download control to run and adapt the source locally.
